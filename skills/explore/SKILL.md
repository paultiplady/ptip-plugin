description: Create or maintain a living exploration document for open-ended research, taste mapping, recommendations, or curation. Use when the user says explore, curate, map a space, continue a discovery thread, or capture iterative findings and preferences.
---

1. Read the project and Personal Context. Resolve the canonical document system from memory; if absent, ask once and treat the answer as a stable preference.
2. Maintain three top-level pages/tabs:
   - **Summary:** human-readable map, conclusions, and shortlist.
   - **AI Prompt:** self-contained objective, anchors/anti-anchors, evidence, frontier hypotheses, unknowns, and next probes.
   - **Results:** brief index plus one nested page per topic with findings, links/media, user reaction, and implication.
3. Preserve feedback verbatim; dedupe results; revise hypotheses; choose the smallest discriminating next batch.
4. Keep the Summary terse, operating state in AI Prompt, and bulk detail in topic pages. Reuse equivalent existing structure.
